# Política Git
El primer commit solo describe metodología y scaffold; no es V0.
Al generar, el pipeline crea commits de referencias validadas y preserva patches respecto a referencia anterior.
Reasignación: checkout nuevo desde commit previo correcto; reparaciones del mismo modelo continúan su workspace.
Exportar al agente solo historia ya ocurrida de su repo de aplicación. No exponer ramas, tags, objetos u otros worktrees con futuro/oráculo.
No sobrescribir intentos fallidos ni reescribir una familia FROZEN; abrir nueva revisión.
