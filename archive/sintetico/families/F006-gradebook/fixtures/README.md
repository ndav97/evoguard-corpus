# Fixture fijo
Libro de calificaciones sintético: 3 categorías con peso en porcentaje (tareas 30, exámenes 50, proyecto 20), 5 tareas evaluables (A1–A5) con su categoría y puntuación máxima, y 20 estudiantes (E001–E020) con la puntuación entera de cada tarea; null indica una tarea no entregada. Incluye notas finales en los límites de cada tramo.
Archivo canónico UTF-8/LF; SHA-256 en family.yaml y provenance.yaml. No regenerar al ejecutar modelos. Cambios requieren revisión y actualización explícita de procedencia.
