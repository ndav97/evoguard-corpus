# T001 — Tamaños no válidos

**Contexto.** `autoVideoFit` (`src/utils/videoFit.ts`) decide si el vídeo de cada participante se muestra recortado (`cover`) o completo con bandas (`contain`), según las proporciones del vídeo y del mosaico. Si alguna proporción es `NaN` devuelve `cover`, pero mientras el vídeo carga también llegan `0` (ancho 0) o `Infinity` (alto 0), y entonces el resultado depende de comparaciones sin sentido.

**Qué hay que hacer**

1. `autoVideoFit` trata como no válida cualquier proporción que no sea un número finito mayor que 0 (`NaN`, `0`, negativos, `Infinity`, `-Infinity`). Si alguna de las dos no es válida, devuelve `cover`.
2. Con proporciones válidas, el resultado no cambia.

- Los tests existentes del proyecto deben seguir pasando.
