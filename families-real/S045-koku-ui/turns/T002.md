# T002 — Ordenar por una función

**Contexto.** Con `sort` (`src/routes/utils/sort.ts`) solo se puede ordenar por una propiedad directa del elemento (`key`). Para ordenar, por ejemplo, por `item.cost.total.value` hay que preparar antes un array auxiliar.

**Qué hay que hacer**

1. `key` puede ser también una función que recibe el elemento y devuelve el valor por el que ordenar. Se acepta tanto en arrays de objetos como en arrays de textos.
2. El valor que devuelve la función se trata igual que el de una propiedad: mismo sentido para `asc` y `desc`, y los valores ausentes (`undefined`, `null`, `NaN`) al final, como en el turno anterior.
3. Exporta el tipo de esa función como `SortKeyFn<T>`.
4. Con una clave que sea el nombre de una propiedad, o sin clave en arrays de textos, todo funciona como hasta ahora.

- Los tests existentes del proyecto deben seguir pasando.
