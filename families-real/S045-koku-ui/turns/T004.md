# T004 — Criterios de desempate

**Contexto.** En las tablas de costes, muchas filas empatan en la clave principal (por ejemplo, el mismo coste) y quedan en el orden en que llegaron. Queremos poder indicar en `sort` (`src/routes/utils/sort.ts`) cómo desempatar.

**Qué hay que hacer**

1. Añade a las opciones de `sort` el campo opcional `thenBy`: una lista de criterios `{ key, direction? }`. `key` puede ser el nombre de una propiedad o una función, como la clave principal, y `direction` vale por defecto `SortDirection.asc`. Exporta el tipo de cada criterio como `SortCriterion<T>`.
2. Cuando dos elementos empatan con la clave principal, se comparan con el primer criterio de `thenBy`; si también empatan, con el segundo, y así sucesivamente. Si empatan en todo, conservan el orden de entrada.
3. Cada criterio sigue las mismas reglas que la clave principal:
   - el sentido de `asc` y `desc` es el de siempre;
   - los valores ausentes van al final de su grupo de empate;
   - con `natural: true`, el orden natural de textos se aplica también a los criterios de desempate.
4. Dos elementos sin valor en la clave principal también se desempatan con `thenBy`.
5. Sin `thenBy`, todo funciona como hasta ahora. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
