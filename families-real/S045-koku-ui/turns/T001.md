# T001 — Valores ausentes al final

**Contexto.** `sort` (`src/routes/utils/sort.ts`) ordena las filas de los informes de costes por una clave (`key`) en una dirección (`SortDirection.asc` o `SortDirection.desc`). Cuando una fila no tiene valor para la clave (`undefined`, `null` o `NaN`), acaba en un sitio impredecible: las comparaciones con esos valores son siempre falsas.

**Qué hay que hacer**

1. Los elementos cuyo valor para la clave es `undefined`, `null` o `NaN` van siempre **al final**, en las dos direcciones.
2. Entre ellos se mantiene el orden que tenían en el array de entrada.
3. El resto de elementos se ordena exactamente como ahora en cada dirección (no cambies el sentido actual de `asc` y `desc`).
4. `sort` sigue devolviendo un array nuevo, sin modificar el de entrada, y sigue funcionando con arrays de textos (sin `key`).

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
