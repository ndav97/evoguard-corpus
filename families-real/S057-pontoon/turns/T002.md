# T002 — Contar caracteres visibles

**Contexto.** `TranslationLength` (`translate/src/modules/editor/components/TranslationLength.tsx`) cuenta la longitud con `length`, que cuenta unidades UTF-16: un emoji como 👍🏽 cuenta como 4, y una `é` escrita con acento combinado cuenta como 2. Para quien traduce, cada uno es un solo carácter.

**Qué hay que hacer**

1. Añade y exporta `countCharacters(text)`, que devuelve el número de caracteres percibidos (grupos de grafemas) usando `Intl.Segmenter` con granularidad `grapheme`. Si `Intl.Segmenter` no existe en el entorno, cuenta los puntos de código (`Array.from(text).length`).
2. `TranslationLength` usa `countCharacters` para la longitud de la traducción y la del original, y también para la cuenta atrás de `MAX_LENGTH`.
3. Lo del turno anterior se mantiene; la estructura que se muestra no cambia.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
