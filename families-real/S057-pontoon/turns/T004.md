# T004 — Mensajes con varios campos

**Contexto.** En mensajes con plurales o atributos, el editor muestra varios campos y `TranslationLength` (`translate/src/modules/editor/components/TranslationLength.tsx`) deja de mostrar nada, justo donde las longitudes varían más.

**Qué hay que hacer**

1. Con más de un campo (y fuera de la vista de código fuente), `TranslationLength` mide el campo con el foco: `focusField.current` del contexto `EditorData`, si es uno de los campos actuales; si no, el primero. El texto de un campo es `field.handle.current.value`.
2. Ese texto se usa igual que la traducción en el caso de un solo campo: para la comparación con la longitud del original o para la cuenta atrás de `MAX_LENGTH` (sin etiquetas).
3. Con un solo campo, todo sigue como hasta ahora. Sin campos, o en vista de código fuente, no se muestra nada.
4. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
