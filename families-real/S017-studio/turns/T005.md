# T005 — Palabras clave para el escritorio y la base de datos

**Contexto.** Para ir al escritorio de WordPress o a phpMyAdmin desde la barra hay que escribir la ruta completa o abrir los atajos. Escribir `admin` hoy lanza una búsqueda en el sitio.

**Qué hay que hacer**

1. En `parseOmniboxInput`, después de quitar los espacios del principio y del final, si el texto es exactamente una de estas palabras (sin distinguir mayúsculas), el resultado es una ruta:
   - `admin` o `wp-admin` → `{ type: 'path', path: '/wp-admin/' }`;
   - `database` o `phpmyadmin` → `{ type: 'path', path: DATABASE_HOME_PATH }`.
2. Cualquier otro texto se interpreta como hasta ahora. Por ejemplo, `administrator` y `admin panel` siguen siendo búsquedas y `wp-admin/plugins.php` sigue siendo la ruta `/wp-admin/plugins.php`.
3. Al enviar la barra, estas rutas se tratan como cualquier otra: `/wp-admin/` pasa por el acceso automático y la de la base de datos se abre tal cual.

**Notas**

- Las direcciones completas del sitio y su *host* sin esquema se siguen aceptando como antes.
- Los tests existentes del proyecto deben seguir pasando.
