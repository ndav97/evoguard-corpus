# T005 — Obtener la última versión de una lista

**Contexto.** En `utils/versionSort.ts` hay utilidades para ordenar versiones (`versionSortComparatorFn`, `sortByVersionInDecreasingOrder`, `getGreaterVersion`), pero para saber cuál es la última versión de un modelo hay que ordenar toda la lista y saltarse el comodín a mano. Además, normalmente no queremos proponer una versión preliminar si existe alguna final.

**Qué hay que hacer**

1. Exporta desde `utils/versionSort.ts` una función `getLatestVersion(versions, options)` que devuelva la versión mayor de la lista según las reglas de `versionSortComparatorFn`, escrita tal cual aparece en la lista (con su `v`, si la tiene).
2. Ignora las entradas vacías y el comodín `WILDCARD_V`.
3. `options` es opcional y admite `includePrerelease` (por defecto `false`):
   - con `false`, las versiones preliminares (las que llevan `-`, como `1.1.0-rc.1`) se ignoran siempre que haya alguna versión sin parte preliminar; si solo hay preliminares, se elige entre ellas;
   - con `true`, se tienen en cuenta todas.
4. Si no queda ninguna versión (lista vacía, solo comodín o sin lista), devuelve `undefined`.

**Notas**

- Las demás funciones del archivo no cambian.
- Los tests existentes del proyecto deben seguir pasando.
