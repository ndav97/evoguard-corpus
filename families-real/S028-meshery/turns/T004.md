# T004 — Sin versiones repetidas ni vacías en la lista ordenada

**Contexto.** `sortByVersionInDecreasingOrder(versions)` (`utils/versionSort.ts`) devuelve las versiones de mayor a menor y añade al principio el comodín `WILDCARD_V` (`All Versions`) cuando hay más de una. Si la lista trae versiones repetidas o vacías, aparecen tal cual y el comodín se añade aunque en realidad solo haya una versión. `sortAndGroupVersionsInModel` usa esta función para las versiones de cada modelo.

**Qué hay que hacer**

1. Descarta las entradas vacías (`''`, `null`, `undefined`).
2. Quita las versiones repetidas (cadenas idénticas); cada versión aparece una sola vez.
3. El comodín se añade solo si quedan **dos o más** versiones distintas: `['1.0.0', '1.0.0']` da `['1.0.0']`, y `['', '']` da `[]`.
4. Lo demás no cambia: orden decreciente con las reglas de `versionSortComparatorFn`, sin modificar la lista recibida, y `undefined` si no se pasa lista.

- Los tests existentes del proyecto deben seguir pasando.
