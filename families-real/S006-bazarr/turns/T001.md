# T001 — Dirección accesible y resumen del desplazamiento de tiempos

**Contexto.** El formulario «Change Time» (`src/components/forms/TimeOffsetForm.tsx`) desplaza los tiempos de los subtítulos seleccionados. El sentido del desplazamiento se elige con un botón que solo muestra un icono (+ o −), sin texto accesible, y no hay forma de ver de un vistazo el desplazamiento total.

**Qué hay que hacer**

1. El botón de dirección tiene nombre accesible `Shift later` cuando el desplazamiento es positivo y `Shift earlier` cuando es negativo. Sigue mostrando el mismo icono y sigue siendo el primer botón del formulario.
2. Cuando algún campo (`hour`, `min`, `sec`, `ms`) es mayor que 0, muestra debajo de los campos el texto `Offset: <signo><HH>:<MM>:<SS>.<mmm>`:
   - el signo es `+` si el desplazamiento es positivo y `-` si es negativo;
   - el tiempo se calcula a partir del total, así que los valores fuera de rango se reparten (por ejemplo, 75 minutos se muestran como `+01:15:00.000`);
   - horas, minutos y segundos llevan dos dígitos y los milisegundos tres.
3. Si todos los campos valen 0 (o están vacíos), no se muestra el resumen.
4. El envío del formulario no cambia.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
