# T005 — Reutilizar el último desplazamiento

**Contexto.** Cuando hay que corregir varios subtítulos con el mismo desfase, el usuario vuelve a escribir el mismo desplazamiento cada vez que abre el formulario.

**Qué hay que hacer**

1. Al enviar el formulario, guarda el último desplazamiento en `localStorage`, con la clave `bazarr-time-offset-last` y como JSON `{"positive": <sentido>, "total": <total en milisegundos>}`. El total es la magnitud ya normalizada, siempre positiva (por ejemplo, 90 s hacia atrás se guarda como `{"positive": false, "total": 90000}`).
2. Al abrir el formulario, si hay un desplazamiento guardado válido (`positive` booleano y `total` entero mayor que 0), muestra un botón con el texto `Use last offset (<desplazamiento>)`, donde `<desplazamiento>` usa el mismo formato que el resumen sin el prefijo `Offset:` (por ejemplo, `Use last offset (+00:00:01.500)`).
3. Al pulsarlo, el sentido y los campos pasan a ese desplazamiento, repartido entre `hour`, `min`, `sec` y `ms`.
4. Si no hay nada guardado, o lo guardado no es válido (o no es JSON), no se muestra el botón y el formulario funciona como siempre.
5. El nuevo botón va después del botón de dirección, que sigue siendo el primero del formulario.

**Restricciones**

- El envío, el resumen y los ajustes rápidos no cambian.
- Los tests existentes del proyecto deben seguir pasando.
