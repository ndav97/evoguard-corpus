# T003 — Filas por página controladas por el componente padre

**Contexto.** En la paginación (`ui/components/Pagination.tsx`) el valor del selector `Rows Per Page` vive solo dentro del componente. Una tabla que ya tiene su propio tamaño de página (por ejemplo, guardado en la URL) no puede indicarle a la paginación qué valor mostrar.

**Qué hay que hacer**

1. Añade a `Props` una prop opcional `perPage?: number`.
2. Si se pasa `perPage`, el componente queda controlado:
   - el selector muestra ese valor y el indicador `Page <actual> of <total>` se calcula con él;
   - al elegir otra opción se llama a `onSelect` como siempre, pero lo que se muestra sigue dependiendo de `perPage` (si el padre no cambia la prop, nada cambia; si la cambia, el selector y el indicador se actualizan).
3. Si `perPage` no está entre `perPageOptions`, se añade a las opciones del selector, que se muestran ordenadas de menor a mayor (con las opciones por defecto y `perPage` 30: 25, 30, 50, 75, 100).
4. Sin `perPage`, el comportamiento es el de ahora.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
