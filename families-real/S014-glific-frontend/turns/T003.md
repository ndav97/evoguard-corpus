# T003 — Actualizar el temporizador cada 30 segundos

**Contexto.** El temporizador se recalcula una vez por minuto. Ahora que muestra minutos en la última hora, puede quedarse casi un minuto desfasado.

**Qué hay que hacer**

1. Recalcula el tiempo restante cada **30 segundos** (en lugar de cada 60).
2. En cada actualización se recalculan el texto visible y el `aria-label`. Por ejemplo, si quedan 25 minutos y la siguiente actualización cae después de completarse otro minuto transcurrido, pasa a `24 min`; si la ventana expira, pasa a `0 hrs` / `Session window expired`.
3. El intervalo se sigue limpiando al desmontar el componente.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
