# T004 — Avisar cuando expira la ventana de sesión

**Contexto.** Cuando la ventana de sesión expira con la conversación abierta, el temporizador pasa a `0 hrs`, pero el resto de la pantalla no se entera (por ejemplo, el editor sigue ofreciendo enviar mensajes libres).

**Qué hay que hacer**

1. Añade a `Timer` la prop opcional `onExpire?: () => void`.
2. Llámala **una vez** cuando la ventana pase de abierta a expirada con el componente montado (por ejemplo, en una de las actualizaciones periódicas).
3. No la llames si la ventana ya estaba expirada al montar el componente, ni de nuevo mientras siga expirada.
4. Si llega un mensaje nuevo (cambia `time`) y la ventana vuelve a abrirse, al expirar otra vez se vuelve a llamar.
5. Sin `onExpire`, el temporizador funciona como hasta ahora.

**Notas**

- El texto visible, el `aria-label`, los estilos y la actualización cada 30 segundos no cambian.
- Los tests existentes del proyecto deben seguir pasando.
