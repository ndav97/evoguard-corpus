# T005 — Añadir varios valores separados por comas

**Contexto.** Para filtrar por varios namespaces en `HealthTypeaheadFilter` (`src/components/health/health-typeahead-filter.tsx`) hay que escribirlos y pulsar Enter uno a uno. Queremos poder escribir o pegar una lista separada por comas.

**Qué hay que hacer**

1. Si el texto contiene comas, se divide en valores por las comas; cada valor se recorta y se descartan los vacíos. Por ejemplo, `my-app, openshift-*` son dos valores.
2. El texto es válido si cada valor lo es con la validación actual (`validateK8SName`). Si alguno no lo es, se muestra el mismo indicador de nombre no válido (`Not a valid Kubernetes name`) y Enter no añade nada.
3. Al pulsar Enter con una lista válida, se llama **una sola vez** a `onChange` con `selected` seguido de los valores nuevos en el orden escrito, omitiendo los que ya estaban seleccionados y los repetidos dentro de la lista. Después se vacía el campo.
4. Si ningún valor de la lista es nuevo, no se llama a `onChange` y el texto se conserva.
5. Mientras el texto contenga comas no se sugieren namespaces: el menú solo muestra la ayuda para pulsar Enter.

**Notas**

- Un único valor sin comas se comporta exactamente igual que antes (sugerencias, aviso de valor ya añadido, Backspace, Escape).
- Los tests existentes del proyecto deben seguir pasando.
