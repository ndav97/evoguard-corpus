# T002 — Avisar cuando el valor ya es un filtro

**Contexto.** En `HealthTypeaheadFilter` (`src/components/health/health-typeahead-filter.tsx`), si el usuario escribe un valor que ya está entre los seleccionados y pulsa Enter, no se añade (bien), pero el texto se borra sin ninguna explicación y parece que se ha aplicado.

**Qué hay que hacer**

1. Cuando el texto escrito (sin espacios al principio ni al final) coincide exactamente con uno de los valores de `selected`, el menú desplegable muestra un elemento deshabilitado con el texto `Already added as a filter` **en lugar** del elemento de ayuda que invita a pulsar Enter (el que empieza por `No matching namespaces` o por `Press Enter`).
2. En ese caso, pulsar Enter no llama a `onChange` y el texto se queda en el campo.
3. Con un valor que no está seleccionado todo sigue como antes: se muestra la ayuda de Enter y, al pulsarlo, se añade el valor y se vacía el campo.

**Notas**

- Usa `t(...)` para el texto nuevo, como el resto del componente.
- Backspace con el campo vacío sigue quitando el último valor.
- Los tests existentes del proyecto deben seguir pasando.
