# T001 — Quitar el último filtro con Retroceso

**Contexto.** En la página Network Health, el filtro de namespaces (`src/components/health/health-typeahead-filter.tsx`, componente `HealthTypeaheadFilter`) permite escribir un nombre o patrón y añadirlo con Enter. Para quitar un valor ya añadido hay que ir hasta su chip en la barra de filtros; queremos el atajo habitual de los campos de etiquetas.

**Qué hay que hacer**

1. Con el foco en el campo y el campo **vacío**, pulsar `Backspace` quita el último valor de `selected`: se llama a `onChange` con la lista sin su último elemento (por ejemplo, de `['openshift-dns', 'my-app']` a `['openshift-dns']`).
2. Cada pulsación quita un solo valor.
3. Si el campo tiene texto, `Backspace` solo edita el texto y no llama a `onChange`.
4. Si no hay valores seleccionados, no se llama a `onChange`.

**Notas**

- El resto del comportamiento del campo (Enter, sugerencias, validación, Escape) no cambia.
- Los tests existentes del proyecto deben seguir pasando.
