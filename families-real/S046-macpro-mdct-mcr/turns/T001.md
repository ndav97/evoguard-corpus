# T001 — Máscara de números enteros

**Contexto.** Los campos numéricos de los informes usan las máscaras de `src/utils/other/mask.tsx` (`comma-separated`, `percentage`, `ratio`, `currency`), que `NumberField` aplica con `applyMask`. Algunos campos, como el número de afiliados, solo admiten números enteros, pero hoy aceptan `12.5` sin quejarse.

**Qué hay que hacer**

1. Añade una máscara `integer` a `maskMap`, implementada en una función exportada `convertToThousandsSeparatedIntegerString(value)` que devuelve `{ isValid, maskedValue }` como las demás.
2. La entrada se limpia y valida como en `comma-separated` (admite comas, `$`, `%`, ceros a la izquierda…). Si el número resultante es entero, el resultado es válido y se muestra con separador de miles y sin decimales: `"1234"` → `"1,234"`, `"12.00"` → `"12"`, `"-5000"` → `"-5,000"`.
3. Si el número tiene parte decimal distinta de cero (`"12.5"`), si la entrada no es un número válido o si está vacía, el resultado no es válido y `maskedValue` es exactamente lo que se escribió.
4. `applyMask(value, "integer", n)` ignora `n`: un entero nunca muestra decimales.
5. Las demás máscaras no cambian.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
