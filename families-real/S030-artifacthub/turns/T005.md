# T005 — Aviso cuando la página escrita no es válida

**Contexto.** En el formulario `Go to page` de `Pagination` (`src/layout/common/Pagination.tsx`), si se escribe una página que no existe no ocurre nada y el usuario no sabe por qué.

**Qué hay que hacer**

1. Al enviar un valor no válido (no es un entero entre 1 y el número de páginas):
   - se muestra un mensaje con `role="alert"` y el texto `Enter a page between 1 and N`, donde N es el número de páginas (por ejemplo `Enter a page between 1 and 5`);
   - el campo `Go to page` queda marcado con `aria-invalid="true"`;
   - el campo conserva el valor escrito y no se llama a `onChange`.
2. En cuanto el usuario modifica el contenido del campo, el mensaje desaparece y el campo deja de estar marcado como no válido.
3. Un envío válido o con el campo vacío no muestra ningún mensaje. Lo demás del formulario funciona como hasta ahora.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
