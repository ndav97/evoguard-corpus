# T004 — Ir directamente a una página

**Contexto.** Con muchas páginas, llegar a una concreta con `Pagination` (`src/layout/common/Pagination.tsx`) obliga a pulsar varias veces.

**Qué hay que hacer**

1. Añade a `Pagination` una prop opcional booleana `showGoTo`. Sin ella, la paginación queda como ahora.
2. Con `showGoTo`, dentro de la navegación y debajo de la lista de páginas, muestra un pequeño formulario con:
   - un campo numérico (`<input type="number">`) con nombre accesible `Go to page`;
   - un botón de envío con el texto `Go`.
3. Al enviar el formulario (pulsando `Go` o Enter en el campo) con el campo relleno:
   - si el valor es un número entero entre 1 y el número de páginas y **distinto** de la página activa, se llama a `onChange` con ese número y el campo se vacía;
   - si es la página activa, no se llama a `onChange`, pero el campo también se vacía;
   - si está fuera de rango (por ejemplo `0` o mayor que el número de páginas), no se llama a `onChange`.
4. Con el campo vacío, enviar no hace nada. El envío nunca recarga la página.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
