# T005 — Contar los avisos repetidos

**Contexto.** Si el mismo aviso se dispara varias veces seguidas (por ejemplo, «Sketch saved.» con guardados automáticos), el usuario no sabe si se repitió o si es el mismo aviso de antes.

**Qué hay que hacer**

1. Si se muestra un aviso con el **mismo texto** que el aviso que está visible, el aviso muestra a continuación del texto un contador ` ×N` con el número de veces seguidas que se ha mostrado (por ejemplo, `Sketch saved. ×2`, luego `×3`).
2. La primera vez no hay contador. Un aviso con otro texto empieza de nuevo sin contador, y también el mismo texto mostrado después de cerrarse el aviso.
3. Funciona con las dos formas de uso de `showToast` (con el texto como primer argumento, o `setToastText` seguido de `showToast(tiempo)`).
4. Guarda lo necesario en el estado del aviso (reducer `toast`). Un estado sin esos campos debe seguir funcionando como un aviso sin contador.
5. Cada repetición sigue durando su tiempo completo, y la variante (`info` o `error`), Escape, «X» y la pausa al pasar el ratón no cambian.

**Notas**

- No añadas botones al aviso.
- Los tests existentes del proyecto deben seguir pasando.
