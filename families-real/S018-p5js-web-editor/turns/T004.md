# T004 — No cerrar el aviso mientras el usuario lo mira

**Contexto.** Los avisos se cierran solos al vencer su tiempo, aunque el usuario tenga el ratón encima o esté a punto de pulsar «X», y algunos mensajes no se alcanzan a leer.

**Qué hay que hacer**

1. Mientras el ratón está sobre el aviso, o el foco está dentro de él, no se cierra automáticamente.
2. Cuando el ratón sale del aviso (o el foco sale de él), el cierre automático vuelve a contar desde cero con el **tiempo completo** del aviso mostrado (el que se pasó a `showToast`, o 1500 ms por defecto).
3. Si el aviso ya está cerrado cuando el ratón o el foco salen, no ocurre nada: no se vuelve a mostrar ni se programa ningún cierre.
4. El botón «X» y Escape siguen cerrando el aviso al momento, también con el ratón encima.

**Notas**

- Mantén la lógica de los temporizadores en `client/modules/IDE/actions/toast.js`, junto a la que ya existe.
- No añadas botones al aviso.
- Los tests existentes del proyecto deben seguir pasando.
