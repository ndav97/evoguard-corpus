# T001 — Cerrar los avisos con Escape

**Contexto.** El editor muestra avisos breves («Sketch saved.», «Settings saved.», …) con el componente `Toast` (`client/modules/IDE/components/Toast.jsx`). Solo se pueden cerrar con el botón «X» o esperando a que desaparezcan.

**Qué hay que hacer**

1. Mientras un aviso está visible, pulsar `Escape` (evento `keydown`) lo cierra (despacha `hideToast()`), esté donde esté el foco dentro de la página.
2. Las demás teclas no lo cierran.
3. Cuando no hay aviso visible, Escape no hace nada y no queda registrado ningún escuchador de teclado (ni en `document` ni en `window`). Al ocultarse el aviso o desmontarse el componente, el escuchador se retira.
4. El botón «X» sigue funcionando igual.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
