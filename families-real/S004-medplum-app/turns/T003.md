# T003 — M recomendado y botón para copiarlo

**Contexto.** La calculadora muestra las opciones «Floor» y «Ceiling», pero no dice qué valor conviene usar. Además, el administrador tiene que copiarlo a mano.

**Qué hay que hacer**

1. Cuando haya resultados, muestra el texto `Recommended M: <valor>`. El valor es el menor entero mayor o igual que `Target m` (es decir, `Math.ceil(targetM)` del resultado de `calculate`).
2. Junto a ese texto, añade un botón `Copy recommended M`. Al pulsarlo:
   - copia el valor al portapapeles con `navigator.clipboard.writeText`, como texto con solo el número;
   - si la copia tiene éxito, muestra el texto `Copied to clipboard`.
3. Si no hay resultados (falta un valor o hay un error de validación), no se muestran ni el texto ni el botón.
4. `Reset to defaults`, la validación y los resultados existentes siguen funcionando igual.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
