# T005 — Avisar de los cambios de orden

**Contexto.** Algunas páginas quieren saber cuándo el usuario cambia el orden de la tabla (por ejemplo, para registrarlo o para sincronizar otro componente).

**Qué hay que hacer**

1. Añade a `KuadrantDataView` la prop opcional `onSortChange?: (columnId: string, direction: 'asc' | 'desc') => void`.
2. Cada vez que el usuario cambia el orden desde la cabecera, se llama con el `id` de la columna y la nueva dirección.
3. No se llama al montar la tabla, aunque el orden inicial venga de la URL o de `defaultSort`.
4. La tabla se ordena y la URL se actualiza exactamente igual que ahora, se pase o no `onSortChange`.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
