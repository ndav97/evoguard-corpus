# T003 — Orden inicial configurable

**Contexto.** Al abrir una lista, la tabla se ordena siempre por la primera columna ordenable, de forma ascendente. Algunas listas se leen mejor ordenadas por otra columna.

**Qué hay que hacer**

1. Añade a `KuadrantDataView` la prop opcional `defaultSort?: { columnId: string; direction?: 'asc' | 'desc' }`. Sin dirección, es ascendente.
2. Si la URL no indica un orden válido para esta tabla, la tabla empieza ordenada por la columna `columnId` en esa dirección. Esto incluye el caso en que la URL nombra una columna que no existe o que no es ordenable.
3. Un orden válido en la URL sigue teniendo prioridad.
4. Si `columnId` no corresponde a una columna ordenable, se ignora y se comporta como ahora.
5. El usuario puede seguir cambiando el orden desde la cabecera, que se guarda en la URL como hasta ahora.

**Notas**

- Sin `defaultSort`, el orden inicial no cambia.
- Los tests existentes del proyecto deben seguir pasando.
