# T001 — Mensaje cuando no hay recursos

**Contexto.** `KuadrantDataView` (`src/components/KuadrantDataView.tsx`) es la tabla común de las listas de recursos del plugin. Cuando una lista está vacía, la tabla muestra solo la cabecera y el usuario no sabe si faltan datos o si no hay nada.

**Qué hay que hacer**

1. Añade a `KuadrantDataView` la prop opcional `emptyMessage?: string`.
2. Si se pasa, los datos están cargados, no hay error y `data` está vacío, el cuerpo de la tabla muestra una única fila con una celda que ocupa todas las columnas y contiene ese texto.
3. Mientras se carga se sigue mostrando el indicador de carga, y con error, el mensaje de error, nunca `emptyMessage`.
4. Con elementos, la tabla se ve como ahora. Sin `emptyMessage`, una tabla vacía se ve exactamente como ahora (solo la cabecera).

**Notas**

- Usa los estados del propio `DataView` de PatternFly, como ya se hace con la carga y el error.
- Los tests existentes del proyecto deben seguir pasando.
