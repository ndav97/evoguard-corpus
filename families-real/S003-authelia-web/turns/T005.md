# T005 — Resumen de requisitos cumplidos

**Contexto.** Con varios requisitos en la lista, el usuario tiene que recorrerla entera para saber cuánto le falta.

**Qué hay que hacer**

1. Siempre que se muestre la lista `Password requirements`, muestra también, fuera de la lista, un texto que resuma cuántos de sus elementos se cumplen:
   - `N of M requirements met`, donde `M` es el número de elementos de la lista, incluido el del nombre de usuario si aparece, y `N` los que se cumplen;
   - si `M` es 1, en singular: `N of 1 requirement met`;
   - si se cumplen todos, el texto es `All requirements met`.
2. El resumen se actualiza al cambiar la contraseña.
3. Cuando no se muestra la lista (modo `ZXCVBN`, sin política o sin requisitos), tampoco se muestra el resumen.
4. La lista, el indicador de fortaleza, los avisos y la validez no cambian.

**Notas**

- Los textos pasan por `i18next` como el resto del componente. Evita `:` y `.` dentro de las claves.
- Los tests existentes del proyecto deben seguir pasando.
