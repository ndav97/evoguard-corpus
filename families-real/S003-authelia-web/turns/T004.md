# T004 — La contraseña no puede contener el nombre de usuario

**Contexto.** Muchos usuarios eligen contraseñas que incluyen su propio nombre de usuario. Queremos que `PasswordMeter` lo detecte y lo trate como un requisito más.

**Qué hay que hacer**

1. Añade la prop opcional `username?: string`. Para la comprobación, el nombre de usuario se usa sin espacios al principio ni al final. Si queda vacío, o la prop no se pasa, no se comprueba nada.
2. Una contraseña contiene el nombre de usuario si el texto del usuario aparece dentro de la contraseña, sin distinguir mayúsculas de minúsculas.
3. En modo `Standard`, con nombre de usuario, la lista `Password requirements` añade al final el elemento `Does not contain your username`, con el mismo formato `✓`/`✗` que el resto. La lista se muestra aunque la política no tenga ningún otro requisito activo.
4. En modo `ZXCVBN`, si la contraseña contiene el nombre de usuario, muestra el texto `Must not contain your username`. La lista de requisitos sigue sin mostrarse en este modo.
5. La validez que se informa con `onValidityChange` tiene en cuenta esta comprobación en los dos modos: una contraseña que contiene el nombre de usuario no es válida, aunque cumpla el resto. Sin política o con la política desactivada sigue siendo siempre válida.
6. El indicador `Strength: <nivel>`, la barra, el aviso de puntuación mínima y los avisos existentes no cambian.

**Notas**

- Los textos nuevos pasan por `i18next` con el propio texto en inglés como clave, como en el resto del componente.
- Los tests existentes del proyecto deben seguir pasando.
