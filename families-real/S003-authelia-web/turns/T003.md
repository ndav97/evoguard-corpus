# T003 — Puntuación mínima y aviso de validez

**Contexto.** Los formularios que usan `PasswordMeter` (cambio y restablecimiento de contraseña) no saben si la contraseña cumple la política. Además, en modo ZXCVBN la política define `min_score`, pero el componente no la tiene en cuenta.

**Qué hay que hacer**

1. Añade la prop opcional `onValidityChange?: (valid: boolean) => void`. El componente la llama con la validez actual al montarse y cada vez que la validez cambia:
   - modo `Standard`: válida si cumple la longitud mínima, la máxima (si `max_length` > 0) y todos los tipos de carácter exigidos;
   - modo `ZXCVBN`: válida si la puntuación es mayor o igual que `min_score`;
   - sin política o con la política desactivada: siempre válida.
2. En modo ZXCVBN, si se ha escrito algo y la puntuación es menor que `min_score`, muestra el texto `Minimum strength required: <nivel>`, con el nombre de nivel ZXCVBN que corresponde a `min_score` (por ejemplo, `Minimum strength required: Good` para 3).
3. En modo estándar nunca se muestra ese texto.
4. El indicador de fortaleza y la lista de requisitos siguen funcionando igual.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
