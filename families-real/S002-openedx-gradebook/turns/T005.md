# T005 — Quitar los filtros de una vez

**Contexto.** Después de buscar y filtrar por usuario, volver a ver todo el historial obliga a borrar la búsqueda y cambiar el selector por separado.

**Qué hay que hacer**

1. Añade un botón con el texto `Clear filters`. Solo es visible cuando hay algún filtro activo:
   - el campo `Search uploads` no está vacío, o
   - el selector `Uploaded by` tiene un usuario elegido, ya sea desde el propio selector o pulsando un usuario en la tabla.

   El selector `Sort by` no es un filtro: cambiarlo no hace aparecer el botón.
2. Al pulsarlo:
   - el campo de búsqueda queda vacío;
   - el selector `Uploaded by` vuelve a `All users`;
   - se muestran todas las cargas con el orden elegido en `Sort by`, que no cambia;
   - el botón desaparece.
3. El botón también debe estar disponible cuando la búsqueda no deja ninguna carga y se muestra el aviso sin coincidencias.

**Restricciones**

- No cambies el comportamiento existente. Escribe los textos nuevos literalmente, sin `messages.js`.
- Los tests existentes del proyecto deben seguir pasando.
