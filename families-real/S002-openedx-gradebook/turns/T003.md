# T003 — Filtrar desde la columna de usuario

**Contexto.** Al revisar el historial, lo más natural es pulsar el nombre de quien hizo una carga para ver todas sus cargas.

**Qué hay que hacer**

1. En la tabla, el usuario de cada fila pasa a ser un botón:
   - su texto visible sigue siendo el nombre del usuario;
   - su nombre accesible es `Show uploads by <usuario>` (por ejemplo, `Show uploads by alice`);
   - conserva la clase CSS `wrap-text-in-cell`.
2. Al pulsarlo, el selector `Uploaded by` pasa a ese usuario y la tabla se filtra en consecuencia. La búsqueda `Search uploads` que hubiera se mantiene.
3. El resumen, el aviso sin coincidencias y el selector siguen funcionando como hasta ahora. Elegir `All users` deshace el filtro.
4. `mapHistoryRows` debe seguir funcionando cuando se llama solo con la fila, como en los tests existentes. En ese caso el usuario se muestra como hasta ahora, en un `<span class="wrap-text-in-cell">`.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
