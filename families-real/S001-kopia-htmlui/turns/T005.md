# T005 — Pausar el refresco automático

**Contexto.** La lista de tareas se vuelve a pedir al servidor cada 3 segundos. Cuando el usuario está revisando una lista larga, los refrescos le cambian la tabla mientras la lee.

**Qué hay que hacer**

1. Añade en la barra de filtros un botón con el texto `Pause auto-refresh`.
2. Al pulsarlo:
   - Se deja de pedir la lista periódicamente.
   - El botón pasa a decir `Resume auto-refresh`.
   - Aparece el texto `Auto-refresh paused.`
3. Al pulsar `Resume auto-refresh`:
   - Se pide la lista al servidor en ese momento, una vez.
   - Se reanuda el refresco periódico.
   - El botón vuelve a decir `Pause auto-refresh` y el texto `Auto-refresh paused.` desaparece.
4. La pausa solo afecta al refresco periódico. Cuando termina `Cancel all running tasks`, la lista se vuelve a pedir igual que ahora, aunque el refresco esté en pausa. La pausa tampoco cambia los filtros, la casilla `Match case` ni el resumen.

**Restricciones**

- No cambies el comportamiento existente.
- Al salir de la página no debe quedar ningún refresco activo.
- Los tests existentes del proyecto deben seguir pasando.
