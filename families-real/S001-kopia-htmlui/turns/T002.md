# T002 — Más estados en el filtro y botón para limpiar filtros

**Contexto.** El filtro de estado de la página de tareas solo ofrece `All`, `Running` y `Failed`, y para volver a ver todas las tareas hay que deshacer cada filtro por separado.

**Qué hay que hacer**

1. Añade al menú del filtro de estado, después de `Failed`, dos opciones:
   - `Success`: muestra solo las tareas con estado `SUCCESS`.
   - `Canceled`: muestra solo las tareas con estado `CANCELED`. Las tareas que se están cancelando (`CANCELING`) no cuentan.

   Al elegir una opción, el botón del menú muestra `Status: Success` o `Status: Canceled`, como ocurre con las opciones actuales.
2. Añade en la barra de filtros un botón con el texto `Clear filters`:
   - Solo es visible cuando hay algún filtro activo: estado distinto de `All`, tipo distinto de `All` o texto de búsqueda no vacío.
   - Al pulsarlo, el estado vuelve a `All`, el tipo vuelve a `All` y el campo de búsqueda queda vacío. Se vuelven a ver todas las tareas y el botón desaparece.
3. El resumen `Showing N of M tasks` y el aviso `No tasks match the current filters.` deben seguir reflejando correctamente los filtros.

**Restricciones**

- No cambies el comportamiento existente.
- Los tests existentes del proyecto deben seguir pasando.
