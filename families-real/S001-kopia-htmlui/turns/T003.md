# T003 — Cancelar de una vez las tareas en curso

**Contexto.** Hoy cada tarea en curso tiene su propio botón para cancelarla. Cuando hay varias, el usuario tiene que cancelarlas una a una.

**Qué hay que hacer**

1. Añade en la barra de filtros un botón con el texto `Cancel all running tasks`. Solo es visible cuando, entre las tareas que se muestran con los filtros actuales, hay al menos una con estado `RUNNING`.
2. Al pulsarlo:
   - Envía una petición `POST /api/v1/tasks/{id}/cancel` (cuerpo `{}`) por cada tarea `RUNNING` visible con los filtros actuales. Las tareas ocultas por los filtros no se cancelan.
   - Mientras haya peticiones pendientes, el botón queda deshabilitado.
   - Cuando terminen todas, vuelve a pedir la lista de tareas al servidor.
3. Resultado:
   - Si todas las peticiones tienen éxito, muestra el texto `Requested cancellation of N tasks.`, con `N` igual al número de tareas enviadas. Si `N` es 1, usa el singular: `Requested cancellation of 1 task.`
   - Si falla alguna, no muestres ese mensaje. En su lugar, muestra una alerta (elemento con rol `alert`) con el texto `Could not cancel K of N tasks.`, donde `K` es el número de peticiones fallidas (singular `task` si `N` es 1).
4. Los filtros, el botón `Clear filters`, el resumen `Showing N of M tasks` y el aviso sin coincidencias siguen funcionando como hasta ahora.

**Restricciones**

- No cambies el comportamiento existente, incluido el botón de cancelar de cada fila.
- Los tests existentes del proyecto deben seguir pasando.
