# T002 — Permitir dejarlo sin valor

**Contexto.** Algunos campos booleanos de los cursos son opcionales: «sin decidir» no es lo mismo que «no». `BooleanField` (`static/js/components/widgets/BooleanField.tsx`) solo permite elegir entre verdadero y falso, y con `value` `null` no marca nada.

**Qué hay que hacer**

1. Añade a `BooleanField` la prop opcional `allowUnset` (por defecto `false`) y la prop `unsetLabel` (por defecto `Not set`).
2. Con `allowUnset`, después de las dos opciones de siempre aparece una tercera opción de radio:
   - con la etiqueta `unsetLabel`, el mismo `name`, `id` igual a `<name>_unset` y `value` vacío;
   - está marcada cuando `value` es `null` o `undefined`;
   - al elegirla, se llama a `onChange` con `{ target: { name, value: null } }`.
3. `value` puede ser `boolean`, `null` o `undefined`. Sin `allowUnset`, el componente muestra y hace exactamente lo de antes (solo dos radios; con `null` no se marca ninguno).
4. Lo del turno anterior (etiquetas propias) se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
