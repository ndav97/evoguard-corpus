# T003 — Campo desactivado

**Contexto.** Cuando un curso está publicado y bloqueado, ciertos campos booleanos deben verse pero no poder cambiarse. `BooleanField` (`static/js/components/widgets/BooleanField.tsx`) no tiene forma de desactivarse.

**Qué hay que hacer**

1. Añade a `BooleanField` la prop opcional `disabled` (por defecto `false`).
2. Con `disabled`, todas las opciones de radio están desactivadas (incluida la de «sin valor» si está `allowUnset`), la opción marcada sigue marcada, y `onChange` no se llama nunca, aunque llegue un evento de cambio.
3. Con `disabled`, el contenedor del campo lleva la clase `text-muted` para que se vea apagado. Sin `disabled`, el contenedor no lleva ninguna clase y las opciones no están desactivadas.
4. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
