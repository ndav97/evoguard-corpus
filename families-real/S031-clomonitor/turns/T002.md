# T002 — Rango de aceptación de un solo día

**Contexto.** Cuando el filtro de fecha de aceptación empieza y termina el mismo día, la barra de filtros muestra el rango completo (`Mar 15, 2021 - Mar 15, 2021`), que es redundante.

**Qué hay que hacer**

1. Si el filtro tiene fecha inicial y final, y las dos, con el formato que ya usa el distintivo, son el mismo día, el distintivo muestra solo esa fecha (por ejemplo, `Mar 15, 2021`).
2. Con fechas distintas se sigue mostrando el rango `<inicio> - <fin>`, y con un solo extremo, `≥ <fecha>` o `≤ <fecha>` como ahora.
3. El botón para quitar el filtro de fecha no cambia.

**Notas**

- El botón `Clear all` no cambia.
- Los tests existentes del proyecto, incluidos sus snapshots, deben seguir pasando.
