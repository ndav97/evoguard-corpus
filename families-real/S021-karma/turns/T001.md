# T001 — Editar con el teclado

**Contexto.** El componente `InlineEdit` (`ui/src/Components/InlineEdit/index.tsx`) muestra un texto que, al hacer clic, se convierte en un campo editable; se usa, por ejemplo, para editar los filtros de la barra superior. El texto ya recibe el foco con el tabulador (`tabIndex={0}`), pero con el teclado no hay forma de entrar en edición.

**Qué hay que hacer**

1. Con el foco en el texto, pulsar `Enter` o la barra espaciadora (tecla `" "`) entra en modo edición, igual que el clic:
   - se llama a `onEnterEditing` (si se pasa);
   - aparece el campo de texto con el valor actual y con el foco.
2. Evita el comportamiento por defecto de esas teclas (por ejemplo, que la barra espaciadora desplace la página).
3. Las demás teclas no hacen nada sobre el texto.
4. El comportamiento del modo edición (Enter guarda, Escape cancela, clic fuera cancela) no cambia.

**Notas**

- No cambies el marcado del texto (sigue siendo el mismo `<span>` con `tabIndex={0}`); hay instantáneas de otros componentes que lo incluyen.
- Los tests existentes del proyecto deben seguir pasando.
