# T002 — No avisar si el valor no ha cambiado

**Contexto.** En `InlineEdit` (`ui/src/Components/InlineEdit/index.tsx`), al pulsar `Enter` en el campo se llama a `onChange` con el texto recortado en cuanto el usuario ha tocado el campo, aunque el resultado sea el mismo valor que ya tenía. En la barra de filtros eso provoca recargas innecesarias.

**Qué hay que hacer**

1. Al pulsar `Enter`, si el texto escrito, sin espacios al inicio ni al final, es igual al valor actual (`value`), **no** se llama a `onChange`; solo se sale del modo edición.
   - Ejemplo: con `value="foo"`, escribir `  foo  ` y pulsar Enter no llama a `onChange`.
2. Si el texto recortado es distinto, se sigue llamando a `onChange` con el texto recortado (por ejemplo, `" a=b "` → `"a=b"`).
3. Vaciar el campo de un valor no vacío sigue llamando a `onChange("")`.
4. Se mantiene la entrada en edición con el teclado (Enter o barra espaciadora sobre el texto).

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
