# T004 — Nombre accesible para el texto editable

**Contexto.** `InlineEdit` (`ui/src/Components/InlineEdit/index.tsx`) se puede activar con el ratón y con el teclado, pero un lector de pantalla no sabe que el texto es interactivo ni qué se está editando.

**Qué hay que hacer**

1. Añade una prop opcional `label` (`string`), por ejemplo `label="Filter"`.
2. Si se pasa `label`:
   - el texto (fuera del modo edición) tiene el rol `button` y el nombre accesible `Edit <label>` (por ejemplo, `Edit Filter`); su contenido visible sigue siendo el valor (o el placeholder si el valor está vacío);
   - en modo edición, el campo de texto tiene como nombre accesible exactamente `label` (por ejemplo, `Filter`).
3. Si no se pasa `label`, el marcado no cambia: el texto no lleva rol ni `aria-label` (hay instantáneas de otros componentes que lo incluyen).
4. Se mantiene todo lo anterior: activación con Enter/barra espaciadora, placeholder, recorte y no avisar si el valor no cambia.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
