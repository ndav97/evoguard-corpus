# T003 — Texto de ayuda cuando no hay valor

**Contexto.** Cuando `InlineEdit` (`ui/src/Components/InlineEdit/index.tsx`) recibe un valor vacío, el texto queda en blanco: no se ve nada ni hay dónde hacer clic.

**Qué hay que hacer**

1. Añade una prop opcional `placeholder` (`string`).
2. Fuera del modo edición, si `value` es `""` y hay `placeholder`, se muestra el texto del `placeholder` en lugar del valor (se puede hacer clic en él o entrar con Enter/barra espaciadora, como siempre).
3. En modo edición, el campo de texto lleva el atributo `placeholder` con ese texto (tanto si el valor está vacío como si no). El placeholder **no** es el valor: al entrar en edición con `value=""`, el campo está vacío.
4. Si `value` no está vacío, se muestra el valor, no el placeholder.
5. Sin la prop `placeholder`, el componente se comporta como antes (el campo no lleva atributo `placeholder`).
6. Se mantiene el comportamiento de `Enter` (recorte, sin aviso si el valor no cambia) y la edición con el teclado.

**Notas**

- Ajusta el ancho del campo (`size`) para que el placeholder se vea entero cuando el campo está vacío.
- Los tests existentes del proyecto deben seguir pasando.
