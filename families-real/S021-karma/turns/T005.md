# T005 — Validar antes de guardar

**Contexto.** `InlineEdit` (`ui/src/Components/InlineEdit/index.tsx`) acepta cualquier texto. Queremos que quien lo usa pueda rechazar valores incorrectos sin salir del modo edición.

**Qué hay que hacer**

1. Añade una prop opcional `validate`: una función que recibe el texto (`string`) y devuelve un mensaje de error (`string`) o `undefined` si el valor es válido.
2. Al pulsar `Enter`, si el valor se va a guardar (es decir, en los casos en que se llamaría a `onChange`), antes se llama a `validate` con ese mismo valor ya recortado (incluido `""` cuando se vacía el campo):
   - si devuelve un mensaje, **no** se llama a `onChange`, se sigue en modo edición con el texto escrito, el campo tiene `aria-invalid="true"` y el mensaje se muestra junto al campo en un elemento con rol `alert`;
   - si devuelve `undefined`, se guarda y se sale del modo edición como hasta ahora.
3. Si el valor no ha cambiado (no se llamaría a `onChange`), no se llama a `validate`: simplemente se sale del modo edición.
4. En cuanto el usuario vuelve a escribir, desaparecen el mensaje y el estado inválido.
5. `Escape` (o el clic fuera) sale del modo edición y descarta el error; al volver a editar no aparece ningún error.
6. Sin `validate`, el comportamiento no cambia.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
