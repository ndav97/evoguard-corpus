# T005 — Longitud máxima del título y la descripción

**Contexto.** El diálogo de guardar búsqueda (`SaveSearchModal.tsx`) acepta títulos y descripciones de cualquier longitud, que luego no caben en la lista de búsquedas guardadas.

**Qué hay que hacer**

1. El título admite como máximo 60 caracteres y la descripción como máximo 200, contando el texto sin los espacios del principio y del final.
2. Si el título supera el límite, el campo `Title` muestra el error `Use 60 characters or fewer`.
3. Si la descripción supera el límite, el campo `Description` muestra el error `Use 200 characters or fewer`.
4. Mientras alguno de los dos supere su límite, el botón `Save` está deshabilitado y enviar el formulario no guarda nada. Los errores desaparecen en cuanto el texto vuelve a estar dentro del límite.

**Notas**

- El error de título repetido (`This title is already in use`) se mantiene.
- Los tests existentes del proyecto deben seguir pasando.
