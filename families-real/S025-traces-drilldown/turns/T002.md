# T002 — Avisar de títulos repetidos

**Contexto.** En el diálogo de guardar búsqueda (`SaveSearchModal.tsx`) se pueden guardar varias búsquedas con el mismo título, y luego es imposible distinguirlas en la lista de búsquedas guardadas.

**Qué hay que hacer**

1. Compara el título escrito con los títulos de las búsquedas guardadas que devuelve `useSavedSearches(dsUid)` (el mismo hook que ya usa el diálogo).
2. Si coincide con alguno, sin distinguir mayúsculas y minúsculas e ignorando los espacios del principio y del final, el campo `Title` muestra el error `This title is already in use` y el botón `Save` queda deshabilitado.
3. El error desaparece en cuanto el título deja de coincidir.
4. Enviar el formulario con un título repetido no guarda nada.

**Notas**

- Un título en blanco sigue sin poder guardarse, pero no muestra este error.
- El aviso que ya existe sobre una búsqueda guardada con la misma consulta no cambia.
- Los tests existentes del proyecto deben seguir pasando.
