# T003 — Mostrar el fallo al guardar dentro del diálogo

**Contexto.** Si `saveSearch` falla, el diálogo de guardar búsqueda (`SaveSearchModal.tsx`) solo publica una notificación global; dentro del propio diálogo no se ve nada y el usuario no sabe si puede volver a intentarlo.

**Qué hay que hacer**

1. Cuando el guardado falla, muestra dentro del diálogo, encima de los campos, una alerta de error con el título `Could not save the search` y el texto `Please try again.`.
2. El diálogo sigue abierto, con el título y la descripción que se habían escrito, los campos habilitados y el botón `Save` disponible para reintentar.
3. Al reintentar con éxito, el diálogo se cierra como siempre y la alerta de error ya no aparece.
4. Mientras no haya fallado ningún guardado, la alerta no se muestra.

**Notas**

- Mantén la notificación global de error que ya se publica.
- Los tests existentes del proyecto deben seguir pasando.
