# T005 — Aviso cuando no se puede guardar la etiqueta

**Contexto.** Guardar una etiqueta puede fallar (por ejemplo, sin conexión), pero el editor no se entera: el campo se queda con el valor nuevo y parece que se guardó.

**Qué hay que hacer**

1. `onSubmit` puede devolver una promesa. Cambia su tipo a `(newLabel: string) => void | Promise<unknown>`. Si no devuelve una promesa, todo funciona como ahora.
2. Si devuelve una promesa y esta se rechaza (al guardar con Enter, al salir del campo o al quitar la etiqueta):
   - el campo vuelve a mostrar la etiqueta original (`props.label`);
   - aparece junto al campo una alerta (elemento con rol `alert`) con el mensaje de Fluent `profile-label-save-error`;
   - no se muestra el aviso de guardado.
3. La alerta desaparece en cuanto el usuario vuelve a escribir en el campo, y también al iniciar un nuevo guardado.
4. Añade la cadena en inglés a `pendingTranslations.ftl`, con un comentario para localizadores:
   `profile-label-save-error = Your label could not be saved. Please try again.`

**Restricciones**

- El contador de caracteres, Escape, el botón para quitar la etiqueta y la sincronización con `props.label` siguen funcionando igual.
- Los tests existentes del proyecto deben seguir pasando.
