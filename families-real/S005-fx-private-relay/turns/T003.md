# T003 — Quitar la etiqueta de una máscara

**Contexto.** El campo de etiqueta exige al menos un carácter visible, así que un usuario que ya puso una etiqueta no puede quitarla.

**Qué hay que hacer**

1. Cuando la máscara tiene etiqueta (`props.label` no vacía), muestra junto al campo un botón (`type="button"`) cuyo nombre accesible es el mensaje de Fluent `profile-label-remove`.
2. Al pulsarlo:
   - se llama **una sola vez** a `onSubmit("")`, también cuando el campo tenía el foco justo antes (la pérdida de foco no debe provocar un guardado adicional);
   - el campo queda vacío.
3. Si la máscara no tiene etiqueta, el botón no se muestra.
4. Añade la cadena en inglés a `pendingTranslations.ftl`, con un comentario:
   `profile-label-remove = Remove label`
5. El contador de caracteres y la cancelación con Escape siguen funcionando igual.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
