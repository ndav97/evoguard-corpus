# T001 — Contador de caracteres en la etiqueta de una máscara

**Contexto.** En el panel de Firefox Relay, cada máscara de correo tiene una etiqueta editable (`src/components/dashboard/aliases/LabelEditor.tsx`) de hasta 50 caracteres. Al llegar al límite, el campo deja de aceptar texto sin avisar.

**Qué hay que hacer**

1. Cuando al campo le queden 10 caracteres o menos (contando el valor actual del campo, incluida la etiqueta inicial), muestra junto a él el mensaje de Fluent `profile-label-characters-remaining`. Pásale la variable `remaining` como **número**, igual a `50 - longitud del valor actual`.
2. El mensaje se actualiza mientras se escribe y desaparece cuando quedan más de 10 caracteres.
3. Añade la cadena en inglés a `pendingTranslations.ftl`, con un comentario para localizadores:
   `profile-label-characters-remaining = { $remaining } characters left`
4. El guardado de la etiqueta (al pulsar Enter o al salir del campo) y el aviso de guardado no cambian.

**Notas**

- Todos los textos visibles del proyecto se obtienen con `useL10n().getString(id, vars)`.
- Los tests existentes del proyecto deben seguir pasando.
