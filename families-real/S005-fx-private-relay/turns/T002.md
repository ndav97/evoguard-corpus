# T002 — Cancelar la edición de la etiqueta con Escape

**Contexto.** Al salir del campo de la etiqueta, el cambio se guarda automáticamente. No hay forma de deshacer una edición a medias.

**Qué hay que hacer**

1. Si el usuario pulsa `Escape` mientras edita la etiqueta:
   - el campo vuelve a mostrar la etiqueta original (`props.label`);
   - el campo pierde el foco;
   - **no** se llama a `onSubmit`, ni siquiera por la pérdida de foco que provoca el propio Escape.
2. Enter y salir del campo sin pulsar Escape siguen guardando como hasta ahora (valor recortado, solo si cambió).
3. El contador de caracteres refleja el valor restaurado.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
