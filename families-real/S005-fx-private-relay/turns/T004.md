# T004 — Mostrar las etiquetas que cambian fuera del editor

**Contexto.** El campo de la etiqueta toma `props.label` solo al montarse. Si la etiqueta de la máscara cambia después (por ejemplo, porque el padre recibe del servidor la etiqueta ya guardada, o porque se editó en otro dispositivo), el campo sigue mostrando el valor viejo.

**Qué hay que hacer**

1. Cuando `props.label` cambie y el campo **no** tenga el foco, el campo pasa a mostrar la nueva etiqueta.
2. Si el campo tiene el foco (el usuario está editando), no se cambia lo que ha escrito.
3. Escape restaura la etiqueta recibida más reciente (`props.label` actual), sin guardar, como hasta ahora.
4. El contador de caracteres refleja siempre el valor que muestra el campo.

**Restricciones**

- El guardado con Enter o al salir del campo, el botón para quitar la etiqueta y el aviso de guardado no cambian.
- Los tests existentes del proyecto deben seguir pasando.
