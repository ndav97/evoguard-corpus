# T002 — Negativos y valores no finitos

**Contexto.** `roundNumber` (`src/shared/utils/roundNumber.ts`) también se usa para diferencias de recuentos entre versiones, que pueden ser negativas. Con un valor negativo nunca entra en el bucle de unidades y devuelve el número completo (`-1,500`); con `NaN` o `Infinity` muestra `NaN` o se queda colgado buscando unidades.

**Qué hay que hacer**

1. Exporta la constante `NOT_A_NUMBER_LABEL = '—'` (raya). Si el valor no es un número finito (`NaN`, `Infinity`, `-Infinity`), `roundNumber` devuelve esa constante.
2. Los negativos se abrevian igual que su valor absoluto y llevan el signo delante: `-1500` → `-2k`, `-999` → `-999`, `-1_499_500` → `-1M`.
3. Si el redondeo da cero, no se muestra signo: `-0.4` → `0` (y `-0` también es `0`).
4. Lo del turno anterior se mantiene.

- Los tests existentes del proyecto deben seguir pasando.
