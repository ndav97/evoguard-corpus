# T004 — Recuentos con sustantivo

**Contexto.** Varias pantallas de UniProt construyen a mano textos como «12k entries» o «1 entry» alrededor de `roundNumber` (`src/shared/utils/roundNumber.ts`), con errores de plural.

**Qué hay que hacer**

1. Añade y exporta en el mismo archivo `formatCount(value, singular, plural?, options?)`, que devuelve el recuento abreviado con `roundNumber` (con `scaleMargin` 1 y las `options` recibidas), un espacio y el sustantivo: `formatCount(12_345, 'entry', 'entries')` → `12k entries`.
2. Se usa el singular solo si el valor es exactamente 1 o -1; en cualquier otro caso (0, decimales, valores no finitos…), el plural.
3. Si no se da el plural, es el singular con una `s` al final: `formatCount(3, 'protein')` → `3 proteins`.
4. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
