# T003 — Decimales opcionales

**Contexto.** En las tarjetas de estadísticas de UniProt, `roundNumber` (`src/shared/utils/roundNumber.ts`) pierde demasiada información: 1 499 y 1 000 se muestran como `1k`. Queremos poder pedir algún decimal.

**Qué hay que hacer**

1. `roundNumber` acepta un tercer parámetro opcional de opciones con el campo `decimals` (exporta su tipo como `RoundNumberOptions`). Es un entero de 0 a 3; por defecto 0. Cualquier otro valor se trata como 0.
2. El valor abreviado se redondea a esa cantidad de decimales (redondeo al más cercano) y se muestra sin ceros finales: `roundNumber(1499, 1, { decimals: 1 })` → `1.5k`, `roundNumber(1000, 1, { decimals: 2 })` → `1k`, `roundNumber(1_234_567, 1, { decimals: 2 })` → `1.23M`.
3. La elección de unidad, el paso a la unidad siguiente cuando el redondeo la alcanza (`999 960` con un decimal → `1M`), `scaleMargin`, los negativos y los valores no finitos funcionan como en los turnos anteriores.
4. Sin opciones, el resultado no cambia.

- Los tests existentes del proyecto deben seguir pasando.
