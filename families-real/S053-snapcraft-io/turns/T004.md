# T004 — Copiar el identificador

**Contexto.** Para reproducir una compilación, quien publica un snap necesita el identificador completo del commit, pero `GitCommitLink` (`static/js/publisher/utils/formatGitCommit.tsx`) solo muestra unos pocos caracteres.

**Qué hay que hacer**

1. Añade a `GitCommitLink` la prop opcional `showCopyButton` (por defecto `false`).
2. Con `showCopyButton` y un identificador válido, detrás del identificador (o del enlace) aparece un botón (`type="button"`) con nombre accesible `Copy commit ID` y el texto `Copy`. El conjunto va dentro de un `<span>` con la clase `git-commit`.
3. Al pulsarlo se copia al portapapeles (`navigator.clipboard.writeText`) el identificador **completo y normalizado**, no el recortado.
   - Si la copia funciona, el texto del botón pasa a `Copied` y un elemento con `role="status"` anuncia `Commit ID copied`.
   - Si falla, el texto del botón sigue siendo `Copy` y el estado anuncia `Could not copy commit ID`.
   - En los dos casos, a los 2 segundos todo vuelve a como estaba (botón `Copy` y estado vacío). Una nueva pulsación reinicia ese plazo.
4. Sin `showCopyButton`, o con un identificador no válido, el componente se muestra exactamente como hasta ahora (sin botón ni envoltorio).
5. Al desmontarse el componente no debe quedar ningún temporizador pendiente que actualice el estado.
6. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
