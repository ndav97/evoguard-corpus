# T003 — Botón para borrar la búsqueda

**Contexto.** La caja de búsqueda (`SearchFilter`, `dashboard/src/components/SearchFilter/SearchFilter.tsx`) ya se puede vaciar con `Escape`, pero con el ratón o en pantallas táctiles no hay forma rápida de hacerlo.

**Qué hay que hacer**

1. Cuando el campo tiene texto, se muestra junto a él un botón con el nombre accesible `Clear search` (puede mostrar solo un icono, por ejemplo `times` de `CdsIcon`).
2. Al pulsarlo, ocurre lo mismo que con `Escape`: el campo se vacía, se llama de inmediato a `onChange("")` y se cancela el aviso pendiente. Además:
   - el foco vuelve al campo de búsqueda;
   - **no** se envía el formulario (no se llama a `submitFilters`).
3. Con el campo vacío, el botón no se muestra.
4. `Escape` y la sincronización con `value` siguen funcionando.

**Notas**

- El campo de texto mantiene su nombre accesible `Search box`.
- Los tests existentes del proyecto deben seguir pasando.
