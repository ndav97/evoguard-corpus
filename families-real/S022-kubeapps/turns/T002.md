# T002 — Escape vacía la búsqueda

**Contexto.** En la caja de búsqueda (`SearchFilter`, `dashboard/src/components/SearchFilter/SearchFilter.tsx`) no hay una forma rápida de volver a ver todos los resultados: hay que borrar el texto a mano y esperar.

**Qué hay que hacer**

1. Con el foco en el campo, pulsar `Escape`:
   - vacía el campo;
   - llama **de inmediato** (sin esperar los 300 ms) a `onChange("")`, una sola vez;
   - cancela cualquier aviso pendiente, de modo que no llegue después un `onChange` con el texto que se acababa de escribir.
2. Si el campo ya estaba vacío y no hay nada pendiente, `Escape` no hace nada (no se llama a `onChange`).
3. Las demás teclas no cambian de comportamiento.
4. Se mantiene la sincronización del campo con la prop `value`.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
