# T004 — Enviar aplica el texto pendiente

**Contexto.** En la caja de búsqueda (`SearchFilter`, `dashboard/src/components/SearchFilter/SearchFilter.tsx`), si el usuario escribe y pulsa Enter enseguida, se llama a `submitFilters` antes de que el padre haya recibido el texto (el aviso `onChange` llega 300 ms después), así que se envía la búsqueda anterior.

**Qué hay que hacer**

1. Al enviar el formulario de búsqueda (el `<form role="search">`, por ejemplo con Enter en el campo), si hay un aviso pendiente:
   - se cancela la espera;
   - se llama de inmediato a `onChange` con el texto actual del campo;
   - y **después** se llama a `submitFilters`.
2. Ese texto no se vuelve a notificar cuando habría terminado la espera (`onChange` se llama una sola vez).
3. Si no hay nada pendiente (no se ha escrito, o la espera ya terminó), solo se llama a `submitFilters`, como hasta ahora.
4. El botón `Clear search`, `Escape` y la sincronización con `value` siguen funcionando igual.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
