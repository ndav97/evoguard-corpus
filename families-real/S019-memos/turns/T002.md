# T002 — Etiquetas legibles para documentos de oficina, Markdown y CSV

**Contexto.** `getFileTypeLabel` (`src/utils/format.ts`) convierte el tipo MIME de un adjunto en una etiqueta corta (`PDF`, `JPEG`, …). Para los documentos de oficina produce etiquetas como `VND.OPENXMLFORMATS-OFFICEDOCUMENT.WORDPROCESSINGML.DOCUMENT`.

**Qué hay que hacer**

1. Añade estas etiquetas (el tipo se compara sin distinguir mayúsculas y sin los parámetros tras `;`, como ya se hace):

   | Tipo MIME | Etiqueta |
   |---|---|
   | `application/msword` | `DOC` |
   | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | `DOCX` |
   | `application/vnd.ms-excel` | `XLS` |
   | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | `XLSX` |
   | `application/vnd.ms-powerpoint` | `PPT` |
   | `application/vnd.openxmlformats-officedocument.presentationml.presentation` | `PPTX` |
   | `text/markdown` | `MD` |
   | `text/csv` | `CSV` |

2. Las etiquetas de los demás tipos no cambian.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
