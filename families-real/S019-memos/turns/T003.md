# T003 — Tipo de archivo a partir del nombre cuando falta el tipo MIME

**Contexto.** Algunos adjuntos llegan sin tipo MIME o con el genérico `application/octet-stream`. Su etiqueta es entonces `File` u `OCTET-STREAM`, aunque el nombre del archivo indique claramente qué es.

**Qué hay que hacer**

1. `getFileTypeLabel(mimeType, filename?)` acepta un segundo argumento opcional con el nombre del archivo.
2. Si el tipo MIME está vacío o es `application/octet-stream` (sin distinguir mayúsculas y sin parámetros), la etiqueta es la **extensión del nombre en mayúsculas**: lo que va después del último punto (`report.final.Pdf` → `PDF`; `backup.tar.gz` → `GZ`).
3. Si no hay nombre o no tiene una extensión útil (sin punto, como `README`; empieza por punto y no tiene otro, como `.env`; o termina en punto, como `archive.`), la etiqueta es `File`.
4. Con un tipo MIME útil se usa el tipo como hasta ahora, sea cual sea el nombre.
5. `getAttachmentMetadata` (`src/components/MemoMetadata/Attachment/attachmentHelpers.ts`) pasa el nombre del adjunto (`attachment.filename`) para que la interfaz muestre estas etiquetas.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
