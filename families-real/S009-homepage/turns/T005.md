# T005 — Ocultar cotizaciones sin datos

**Contexto.** Cuando la API no tiene datos de un símbolo, el widget lo muestra con un aviso de error que ocupa sitio sin aportar nada.

**Qué hay que hacer**

1. Admite la opción `hideMissing` en las `options` del widget. Solo cuando vale exactamente `true`, se ocultan las cotizaciones que no tienen precio **ni** porcentaje de cambio (ambos `null` o ausentes).
2. Una cotización a la que solo le falta uno de los dos valores se sigue mostrando como ahora.
3. Las cotizaciones ocultas por `hideMissing` no cuentan para `limit` ni para el contador `+K`: primero se ordena, después se quitan las que no tienen datos y por último se aplica el límite.
4. Sin `hideMissing`, o con cualquier valor que no sea `true`, el widget funciona como hasta ahora.

**Restricciones**

- No modifiques los datos que devuelve `useSWR`.
- El botón de alternancia accesible, `sort`, `limit` y la vista recordada no cambian.
- Los tests existentes del proyecto deben seguir pasando.
