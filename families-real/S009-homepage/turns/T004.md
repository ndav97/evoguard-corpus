# T004 — Limitar el número de cotizaciones

**Contexto.** Con una watchlist larga, el widget `stocks` ocupa demasiado espacio en la barra de información.

**Qué hay que hacer**

1. Admite la opción `limit` en las `options` del widget. Si es un número entero mayor o igual que 1, se muestran solo las primeras `limit` cotizaciones, después de aplicar el orden de `sort`.
2. Si quedan cotizaciones sin mostrar, añade dentro del botón, después de las cotizaciones, un elemento cuyo texto es `+K`, donde `K` es el número de cotizaciones ocultas (por ejemplo, `+3`).
3. Las entradas nulas de `data.stocks` no cuentan, ni para el límite ni para `K`.
4. Sin `limit`, con un límite mayor o igual que el número de cotizaciones, o con un valor que no sea un entero positivo (0, negativos, decimales o texto), se muestran todas y no aparece el contador.

**Restricciones**

- El botón de alternancia accesible, la opción `sort` y la vista recordada por watchlist no cambian.
- No modifiques los datos que devuelve `useSWR`.
- Los tests existentes del proyecto deben seguir pasando.
