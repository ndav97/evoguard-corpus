# T003 — Recordar la vista elegida por watchlist

**Contexto.** Cada vez que se recarga la página, el widget `stocks` vuelve a mostrar precios aunque el usuario hubiera elegido el porcentaje de cambio. Queremos recordar esa elección en el navegador.

**Qué hay que hacer**

1. Al alternar la vista, guarda la elección en `localStorage` con la clave `homepage-stocks-view:<watchlist>` (donde `<watchlist>` es el valor de `options.watchlist` tal cual) y el valor `"percent"` o `"price"`.
2. Al montar el widget, si esa clave vale `"percent"`, se muestra directamente el porcentaje de cambio. Con cualquier otro valor, o sin valor, se muestran precios.
3. Cada watchlist tiene su propia elección: un widget con otra watchlist no se ve afectado.
4. Si el widget no tiene `options.watchlist`, la alternancia funciona pero no se guarda nada.
5. Si `localStorage` no está disponible o lanza una excepción, el widget sigue funcionando sin recordar la vista.
6. Lee `localStorage` después del montaje (no durante el render), para que el HTML generado en el servidor coincida con el primer render del cliente.

**Restricciones**

- El botón accesible (T001) y la opción `sort` (T002) se mantienen.
- Los tests existentes del proyecto deben seguir pasando.
