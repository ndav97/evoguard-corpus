# T001 — Descriptor en singular cuando el total es 1

**Contexto.** El componente `ChipGroup` (`src/components/ChipGroup/ChipGroup.tsx`) resume recuentos por estado (por ejemplo, unidades o máquinas de una aplicación) y, si recibe la prop `descriptor`, muestra antes de los chips el total seguido de una etiqueta: `3 Units`, `3 Machines` o `3 Local applications`. Cuando el total es 1, el texto queda en plural («1 Units»), lo que es incorrecto.

**Qué hay que hacer**

1. Cuando la suma de todos los recuentos es exactamente 1, el descriptor usa la forma singular:
   - `descriptor="units"` → `1 Unit`;
   - `descriptor="machines"` → `1 Machine`;
   - `descriptor="localApps"` → `1 Local application`.
2. Con cualquier otro total se mantiene el plural actual (`2 Machines`, `3 Units`, …).
3. El resto del componente no cambia: los chips con recuento 0 no se muestran, sin descriptor (`null` o desconocido) no se muestra el texto del total, y con total 0 no se muestra nada.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
