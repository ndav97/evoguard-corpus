# T005 — Límite de chips visibles

**Contexto.** En algunas cabeceras hay poco espacio y `ChipGroup` (`src/components/ChipGroup/ChipGroup.tsx`) puede mostrar muchos estados. Queremos limitar cuántos chips se ven.

**Qué hay que hacer**

1. Añade a `ChipGroup` una prop opcional numérica `maxChips`.
2. Si el número de chips que se mostrarían (los de recuento mayor que 0) supera `maxChips`:
   - solo se muestran los `maxChips` primeros, en el orden habitual (de mayor a menor recuento);
   - a continuación se añade un chip de resumen con el texto `+N more`, donde N es el número de chips ocultos (por ejemplo `+2 more`).
3. Si no se supera el límite, o no se pasa `maxChips`, no hay chip de resumen. Los chips con recuento 0 no cuentan.
4. El texto del descriptor sigue sumando los recuentos de **todos** los chips, también los ocultos.
5. El chip de resumen nunca es un botón, aunque se pase `onChipClick`; los chips visibles siguen siendo botones en ese caso.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
