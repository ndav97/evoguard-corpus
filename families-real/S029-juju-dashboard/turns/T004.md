# T004 — Chips pulsables

**Contexto.** Queremos poder usar `ChipGroup` (`src/components/ChipGroup/ChipGroup.tsx`) como filtro rápido: al pulsar un chip, la pantalla que lo contiene filtrará por ese estado.

**Qué hay que hacer**

1. Añade a `ChipGroup` una prop opcional `onChipClick` con la firma `(label: string) => void`.
2. Si se pasa `onChipClick`, cada chip visible se renderiza como un botón (`<button type="button">`) cuyo nombre accesible es el texto del chip (por ejemplo `2 blocked`). Al pulsarlo se llama a `onChipClick` con la etiqueta del chip, es decir, la clave del objeto `chips` (`"blocked"`).
3. Los botones respetan el orden y las reglas actuales: mismo orden por recuento, no hay botón para chips con recuento 0, y siguen dentro del grupo.
4. Si no se pasa `onChipClick`, los chips se muestran como hasta ahora y no hay ningún botón.

**Notas**

- Conserva el texto y las clases del contenido de cada chip.
- Los tests existentes del proyecto deben seguir pasando.
