# T003 — El grupo de chips como grupo accesible

**Contexto.** El contenedor de `ChipGroup` (`src/components/ChipGroup/ChipGroup.tsx`, el elemento con la clase `chip-group`) es un `div` sin semántica: un lector de pantalla no sabe que los chips forman un resumen ni de qué.

**Qué hay que hacer**

1. El contenedor de los chips debe exponerse con el rol `group`.
2. Su nombre accesible es:
   - si hay descriptor, exactamente el mismo texto del total que se muestra (por ejemplo `6 Units` o `1 Machine`);
   - si no hay descriptor, `Status counts`.
3. Los chips siguen dentro de ese contenedor. Cuando el total es 0 no se muestra nada (tampoco el grupo).

**Notas**

- No cambies los textos visibles del componente.
- Los tests existentes del proyecto deben seguir pasando.
