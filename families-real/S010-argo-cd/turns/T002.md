# T002 — Filtrar la lista desde las leyendas de Sync y Health

**Contexto.** En la vista *Summary*, las leyendas de los gráficos muestran, por ejemplo, `Synced (3)` o `Degraded (1)`. Queremos que el usuario pueda pulsar una entrada para filtrar la lista de aplicaciones por ese estado.

**Qué hay que hacer**

1. Añade a `ApplicationsSummary` la prop opcional `onFilter?: (type: 'sync' | 'health', status: string) => void`.
2. Si se pasa, cada entrada de las leyendas de **Sync** y **Health** es un `<button type="button">` cuyo texto es el de siempre (`Synced (3)`). Al pulsarlo se llama a `onFilter('sync', 'Synced')` o a `onFilter('health', 'Degraded')`, según la leyenda.
3. Las entradas con 0 aplicaciones se muestran como botones deshabilitados.
4. La leyenda de **Hydrator** sigue siendo texto, sin botones.
5. Sin `onFilter`, las leyendas se ven exactamente como hasta ahora (sin botones).
6. En `applications-list.tsx`, pasa `onFilter` al resumen de modo que se sustituya el filtro de sincronización (`syncFilter`) o de salud (`healthFilter`) de las preferencias por `[status]`, usando el mismo mecanismo con el que ya se cambian los filtros (`onAppFilterPrefChanged`).
7. Estiliza los botones para que parezcan texto (sin fondo ni borde), con subrayado al pasar el ratón si están habilitados.

**Restricciones**

- Los porcentajes de T001 se mantienen.
- Los tests existentes del proyecto deben seguir pasando.
