# T004 — Espera media de una cola

**Contexto.** Además de la métrica que calcula el servidor, la vista de una cola quiere mostrar la espera media de los pacientes que aparecen en ella, calculada en el navegador con las horas de llegada. `src/wait-time.ts` ya sabe calcular la espera de cada uno.

**Qué hay que hacer**

1. Añade y exporta `getAverageWaitTimeInMinutes(startTimes, now = new Date())`:
   - `startTimes` es un array de horas de llegada (`Date`, cadenas ISO, marcas de tiempo, o `null`/`undefined`), o `null`/`undefined`;
   - la espera de cada entrada se calcula con `getWaitTimeInMinutes(startedAt, now)`; las entradas para las que da `null` se ignoran;
   - devuelve la media aritmética de esas esperas (sin redondear) o `null` si no queda ninguna.
2. El array recibido no se modifica.
3. Lo de los turnos anteriores se mantiene.
