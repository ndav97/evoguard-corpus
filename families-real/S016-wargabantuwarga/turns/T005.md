# T005 — Restablecer filtros y orden

**Contexto.** Después de elegir varios filtros o cambiar el orden, volver a la vista inicial obliga a deshacer cada selector por separado.

**Qué hay que hacer**

1. Añade al formulario un botón (`type="button"`) con el texto `Atur ulang filter`. Solo se muestra si hay algún filtro con valor elegido o si el orden es distinto del orden inicial (el primero de `sortSettings`, o vacío si no hay).
2. Al pulsarlo:
   - todos los filtros vuelven a `Semua` (sin valor) y el orden vuelve al inicial;
   - se llama de inmediato a `onSubmitKeywords(palabras, {}, ordenInicial)`, con las palabras clave recortadas, igual que al cambiar un filtro;
   - el texto del campo de búsqueda no cambia;
   - no se envía el formulario;
   - el botón desaparece.
3. Si el usuario vuelve a dejar todo como al principio con los propios selectores, el botón también desaparece.

**Notas**

- La interfaz está en indonesio; usa el texto `Atur ulang filter` tal cual.
- Los tests existentes del proyecto deben seguir pasando.
