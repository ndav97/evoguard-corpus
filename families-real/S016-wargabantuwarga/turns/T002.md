# T002 — Botón para borrar la búsqueda

**Contexto.** Para volver a ver todos los resultados hay que borrar a mano el texto del campo de búsqueda.

**Qué hay que hacer**

1. Cuando el campo de búsqueda tiene texto, muestra junto a él un botón con el nombre accesible `Hapus pencarian` (puede mostrar solo un icono «X»).
2. Al pulsarlo:
   - el campo queda vacío y el botón desaparece;
   - se llama **de inmediato** (sin esperar la búsqueda automática) a `onSubmitKeywords("", filtros, orden)`, conservando los filtros y el orden actuales;
   - **no** se envía el formulario (el envío borra los filtros).
3. Con el campo vacío, el botón no se muestra.

**Notas**

- La interfaz está en indonesio; usa el texto `Hapus pencarian` tal cual.
- Los tests existentes del proyecto deben seguir pasando.
