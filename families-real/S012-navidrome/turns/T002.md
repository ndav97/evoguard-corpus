# T002 — Aviso en el diálogo cuando falla el guardado

**Contexto.** Si falla la creación de la lista, el diálogo solo muestra una notificación genérica que desaparece sola. El usuario no ve dentro del diálogo qué pasó.

**Qué hay que hacer**

1. Si el guardado falla (cualquiera de las dos llamadas a `dataProvider.create` es rechazada), muestra dentro del diálogo un mensaje con `role="alert"` cuyo texto sea exactamente `Could not save the playlist.`
2. Tras el fallo, el diálogo sigue abierto, el nombre escrito se conserva y el botón de guardar vuelve a estar disponible para reintentar.
3. El aviso desaparece:
   - en cuanto el usuario modifica el nombre;
   - al iniciar un nuevo guardado;
   - al cerrar el diálogo.
4. La notificación actual (`ra.page.error`) se mantiene.

**Notas**

- Mientras no haya fallado ningún guardado, no debe haber ningún elemento con `role="alert"` en el diálogo.
- Los tests existentes del proyecto deben seguir pasando.
