# T003 — No guardar una cola vacía

**Contexto.** Hoy se puede guardar una lista aunque la cola de reproducción esté vacía, lo que crea una lista sin canciones.

**Qué hay que hacer**

1. Si la cola está vacía:
   - el elemento `data-testid="save-queue-count"` muestra exactamente `The queue is empty`;
   - el botón de guardar (`data-testid="save-queue-save"`) está deshabilitado aunque se haya escrito un nombre;
   - pulsar Enter en el campo del nombre no crea ninguna lista.
2. Con canciones en la cola todo sigue como antes: el recuento, el guardado con el botón o con Enter y el aviso de error.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
