# T001 — Nombre recortado y recuento de canciones al guardar la cola

**Contexto.** El diálogo «Save Queue» (`src/dialogs/SaveQueueDialog.jsx`) crea una lista de reproducción con las canciones de la cola actual. Hoy el nombre se envía tal como se escribe, con espacios sobrantes incluidos, y el diálogo no dice cuántas canciones se van a guardar.

**Qué hay que hacer**

1. Al guardar, crea la lista con el nombre **sin espacios al inicio ni al final**: `dataProvider.create('playlist', { data: { name } })` debe recibir el nombre recortado.
2. Debajo del campo del nombre, muestra cuántas canciones de la cola se guardarán, en un único elemento con `data-testid="save-queue-count"` cuyo texto sea exactamente:
   - `N songs will be saved` (por ejemplo, `3 songs will be saved`);
   - `1 song will be saved` cuando la cola tiene una sola canción.
3. El resto no cambia: después de crear la lista se añaden las canciones de la cola (`playlistTrack`), se notifica, se cierra el diálogo y se navega a la lista.

**Notas**

- Escribe el texto del recuento tal cual, en inglés; no hace falta añadir claves de traducción.
- Los tests existentes del proyecto deben seguir pasando.
