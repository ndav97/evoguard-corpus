# T002 — Paso entre los valores permitidos

**Contexto.** Además del rango, queremos poder indicar cada cuánto se pueden introducir valores en una pregunta numérica (por ejemplo, de 0,5 en 0,5).

**Qué hay que hacer**

1. Añade, después de los campos de mínimo y máximo, un campo de texto con la etiqueta `Step between allowed values` (`t('stepValue', 'Step between allowed values')`).
2. El campo muestra y edita `questionOptions.step`, guardando el texto tal cual y sin modificar las demás opciones de la pregunta.
3. El paso es válido si está vacío o es un número (con el mismo criterio que el mínimo y el máximo) **mayor que 0**. Si no lo es, el campo se marca como inválido con el texto `Step must be a number greater than 0` (`t('invalidStep', …)`).
4. La validación de mínimo y máximo no cambia.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
