# T001 — Validar que el mínimo y el máximo sean números

**Contexto.** En el constructor de formularios, las preguntas numéricas tienen dos campos para el valor mínimo y el máximo permitidos (`src/components/interactive-builder/modals/question/question-form/rendering-types/inputs/number/number.component.tsx`). Hoy solo se avisa cuando el mínimo es mayor que el máximo; si se escribe `abc` o `1..5`, no se avisa de nada.

**Qué hay que hacer**

1. Un valor de mínimo o máximo es válido si está vacío o es un número completo: entero o decimal, con signo menos opcional y punto como separador decimal (por ejemplo `5`, `-2.5`, `0.5`, `.5`).
2. Si el mínimo o el máximo no es válido, **ese** campo se marca como inválido (`invalid`) con el texto `Enter a valid number` (usa `t('invalidNumber', 'Enter a valid number')`). El otro campo no se marca por ello.
3. El aviso actual `Min value cannot be greater than max` se mantiene; si un campo tiene un valor no válido, en ese campo se muestra el aviso de número no válido.
4. El valor escrito se sigue guardando tal cual en `questionOptions.min` / `questionOptions.max`.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
