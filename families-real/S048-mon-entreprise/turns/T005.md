# T005 — Generar rutas con comodín

**Contexto.** `matchPath` (`source/lib/navigation/pathUtils.ts`) entiende los patrones con comodín final (`/iframes/*`), pero `generatePath` los deja tal cual: `generatePath('/iframes/*', { '*': 'simulateur/salaire' })` devuelve `/iframes/*`.

**Qué hay que hacer**

1. Cuando el patrón termina en `/*`, `generatePath` sustituye ese final por el valor de `params['*']`:
   - el valor se divide por `/`, se descartan los segmentos vacíos y cada segmento se codifica con `encodeURIComponent`, conservando las `/` entre ellos: `{ '*': 'a b/é' }` → `/iframes/a%20b/%C3%A9`;
   - si no hay valor o queda vacío, el resultado es el prefijo (`/iframes`), o `/` si el patrón era solo `/*`.
2. Se puede combinar con parámetros normales y opcionales antes del comodín, y con la consulta del turno 3: `generatePath('/:lang?/docs/*', { lang: 'en', '*': 'guide/intro' }, { v: 2 })` → `/en/docs/guide/intro?v=2`.
3. Un `*` que no está al final del patrón no se toca. `generatePath` sin el objeto de parámetros sigue devolviendo el patrón tal cual.
4. Lo que genera `generatePath` con un comodín vuelve a dar el mismo valor con `matchPath` (sin las barras sobrantes).
5. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
