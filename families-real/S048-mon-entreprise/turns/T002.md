# T002 — Parámetros opcionales

**Contexto.** Algunos simuladores tienen una página general y páginas por paso (`/simulateurs/salaire` y `/simulateurs/salaire/resultat`). Hoy hacen falta dos patrones para cubrirlas con `matchPath` (`source/lib/navigation/pathUtils.ts`).

**Qué hay que hacer**

1. Un parámetro terminado en `?` (`:etape?`) es opcional.
2. `matchPath`:
   - acepta la ruta con o sin ese segmento: `matchPath('/simulateurs/:slug/:etape?', '/simulateurs/salaire')` → `{ params: { slug: 'salaire' } }` (el parámetro opcional no aparece si falta), y con `/simulateurs/salaire/resultat` → `{ params: { slug: 'salaire', etape: 'resultat' } }`;
   - un patrón puede tener varios parámetros opcionales y en cualquier posición; si hay varias formas de encajar, se asignan los segmentos a los parámetros de izquierda a derecha;
   - el nombre del parámetro no incluye el `?`.
3. `generatePath` omite el segmento (junto con su `/`) cuando no se da valor para un parámetro opcional o el valor es el texto vacío: `generatePath('/simulateurs/:slug/:etape?', { slug: 'salaire' })` → `/simulateurs/salaire`. Si se da, se inserta codificado como los demás. Si el resultado quedara vacío, devuelve `/`.
4. Sin parámetros opcionales todo funciona como hasta ahora, incluida la decodificación del turno anterior. `generatePath` sin el objeto de parámetros sigue devolviendo el patrón tal cual.

**Notas**
