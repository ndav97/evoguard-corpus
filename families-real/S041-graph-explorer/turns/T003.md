# T003 — Redondear a un número de decimales

**Contexto.** En los diálogos de estilo, valores como el grosor de línea no necesitan más de uno o dos decimales, pero `NumberInput` (`src/components/NumberInput.tsx`) acepta y guarda lo que se escriba (`1.23456`).

**Qué hay que hacer**

1. Añade a `NumberInput` la prop opcional `precision?: number`: cuántos decimales se conservan.
2. Cuando termina una edición (el campo pierde el foco), el número escrito se redondea a `precision` decimales, redondeando las mitades hacia arriba como `Math.round` (con `precision={0}`, `2.5` pasa a `3`). Si el resultado es distinto de lo escrito, se avisa con `onValueChange` y el campo lo muestra.
3. Mientras se escribe no se redondea nada.
4. El redondeo se hace **antes** de aplicar `min` y `max`: el resultado final siempre queda dentro del rango (con `precision={0}` y `max={2.5}`, escribir `2.4` deja `2`, y escribir `2.7` deja `2.5`).
5. Sin `precision`, o con un valor que no sea un entero mayor o igual que 0, no se redondea.
6. `precision` no se pasa al `<input>`.
7. Lo de los turnos anteriores (límites al salir del campo, `Escape` para cancelar) se mantiene.

**Notas**

- Los tests existentes de `NumberInput` deben seguir pasando.
