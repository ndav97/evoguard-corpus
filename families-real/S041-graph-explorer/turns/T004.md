# T004 — Valor por defecto para el campo vacío

**Contexto.** En los diálogos de estilo, si se borra el contenido de un `NumberInput` (`src/components/NumberInput.tsx`) y se sale del campo, el estilo queda con `undefined`. Para campos como el grosor de línea eso no tiene sentido: debería volver a un valor razonable.

**Qué hay que hacer**

1. Añade a `NumberInput` la prop opcional `emptyValue?: number`.
2. Si una edición termina (el campo pierde el foco) con el campo vacío o con un texto que no es un número, y se ha pasado `emptyValue`, se avisa con `onValueChange(emptyValue)` y el campo lo muestra.
3. `emptyValue` se usa tal cual: no se redondea con `precision` ni se ajusta a `min`/`max`.
4. Mientras se escribe se sigue avisando de `undefined` al vaciar el campo, como ahora.
5. Sin `emptyValue`, el campo vacío se comporta como hasta ahora. `emptyValue` no se pasa al `<input>`.
6. `Escape` sigue cancelando la edición y volviendo al valor anterior, aunque el campo esté vacío; en ese caso no se usa `emptyValue`.
7. Lo de los turnos anteriores (límites, `Escape`, `precision`) se mantiene.

**Notas**

- Los tests existentes de `NumberInput` deben seguir pasando.
