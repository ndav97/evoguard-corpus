# T001 — Progreso sin tareas o fuera de rango

**Contexto.** En la portada de Sensei, `Progress` (`assets/home/tasks-section/progress.js`) muestra el porcentaje de tareas de configuración completadas. Si todavía no hay tareas (`totalTasks` igual a 0), muestra `NaN%` y una barra con ancho `NaN%`; con datos inconsistentes (más tareas completadas que tareas, o negativos) muestra porcentajes como `150%`.

**Qué hay que hacer**

1. Añade y exporta en el mismo archivo `getProgressPercentage( totalTasks, completedTasks )`, que devuelve el porcentaje completado redondeado al entero más cercano y limitado al rango de 0 a 100.
2. Si `totalTasks` no es un número mayor que 0, o `completedTasks` no es un número finito, devuelve 0.
3. `Progress` usa esa función para el número que muestra, para `aria-valuenow` y para el ancho de la barra. Con datos normales se ve exactamente igual que ahora.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
