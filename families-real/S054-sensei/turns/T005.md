# T005 — Anunciar las tareas completadas

**Contexto.** Cuando se completa una tarea de configuración, la barra de `Progress` (`assets/home/tasks-section/progress.js`) se actualiza en silencio. Quien usa un lector de pantalla no se entera.

**Qué hay que hacer**

1. `Progress` incluye siempre, al final del contenedor, un `<span>` con `role="status"` y la clase `screen-reader-text`. Al principio está vacío.
2. Cuando, de un render al siguiente, aumenta el número de tareas completadas (redondeado y limitado como en turnos anteriores), el estado anuncia:
   - `"Task completed. <descripción>"`, donde `<descripción>` es el texto de `getProgressText` (por ejemplo, `"Task completed. 4 of 10 tasks completed"`);
   - o `"All tasks completed"` si con ello se completan todas.
   Los dos textos son traducibles (dominio `sensei-lms`).
3. Si el número disminuye, el estado se vacía. Si no cambia, el anuncio se mantiene. El estado inicial nunca se anuncia, aunque ya haya tareas completadas.
4. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
