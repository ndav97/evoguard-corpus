# T002 — Recuento de coincidencias anunciado a lectores de pantalla

**Contexto.** Cuando hay texto de búsqueda, la barra muestra junto al campo el número de spans que coinciden (elemento con la clase `TracePageSearchBar--count`). Ese número no tiene contexto para un lector de pantalla y sus cambios no se anuncian.

**Qué hay que hacer**

1. El elemento del recuento (el mismo `<span className="TracePageSearchBar--count">`) debe:
   - tener `aria-label` igual a `N matching spans` (por ejemplo, `3 matching spans` o `0 matching spans`), o `1 matching span` cuando hay una sola coincidencia;
   - tener `aria-live="polite"`, para que se anuncien los cambios.
2. El texto visible del recuento sigue siendo solo el número.
3. Sin texto de búsqueda, el recuento sigue sin mostrarse.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
