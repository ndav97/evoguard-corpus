# T003 — Escape vacía antes de salir del campo

**Contexto.** Hoy, pulsar `Escape` con el campo de búsqueda enfocado solo le quita el foco, aunque tenga texto.

**Qué hay que hacer**

1. Si el campo está enfocado y tiene texto, pulsar `Escape` hace lo mismo que el botón `Clear search`: vacía el campo, llama a `onSearch('')` inmediatamente y mantiene el foco en el campo.
2. Si el campo está enfocado y vacío, `Escape` le quita el foco, como ahora.
3. El botón `Clear search`, el anuncio de resultados y el atajo `/` para enfocar siguen funcionando igual.

**Restricciones**

- Los tests existentes del proyecto deben seguir pasando.
