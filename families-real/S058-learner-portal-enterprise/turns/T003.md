# T003 — Estado de caducidad

**Contexto.** Para colorear el aviso de la barra lateral necesitamos clasificar cuánto falta para que caduque una subvención. En `src/components/dashboard/sidebar/utils.js` ya tenemos `getDaysUntilExpiration`.

**Qué hay que hacer**

1. Exporta las constantes `EXPIRATION_WARNING_DAYS = 60` y `EXPIRATION_URGENT_DAYS = 14`.
2. Añade y exporta `getExpirationStatus(expirationDate, now = new Date(), { warningDays, urgentDays } = {})`, que devuelve:
   - `null` si la fecha no es válida (cuando `getDaysUntilExpiration` da `null`);
   - `'expired'` si ya caducó (días negativos);
   - `'urgent'` si quedan `urgentDays` días o menos (incluido el mismo día);
   - `'warning'` si quedan `warningDays` días o menos;
   - `'active'` en otro caso.
3. `warningDays` y `urgentDays` valen por defecto las constantes anteriores. Si alguno no es un entero mayor o igual que 0, se usa su valor por defecto. Las comprobaciones se hacen en el orden de la lista, así que `'urgent'` tiene prioridad sobre `'warning'`.
4. Lo de los turnos anteriores se mantiene.

**Notas**

- Los tests existentes del proyecto deben seguir pasando.
