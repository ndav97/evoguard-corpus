# T005 — Distinguir mayúsculas solo si el filtro las usa

**Contexto.** `matchesResourceName(resourceName, filter)` (`src/ResourceNameFilter.tsx`) compara siempre sin distinguir mayúsculas. Hay proyectos con recursos que solo se diferencian por las mayúsculas (`Worker` y `worker-db`, por ejemplo) y no se pueden separar con el filtro.

**Qué hay que hacer**

1. Cada palabra o alternativa del filtro (las partes separadas por espacios y comas, sin el `-` de exclusión) que contenga **alguna letra mayúscula** se busca distinguiendo mayúsculas. Con `Worker`, pasa `Worker` pero no `worker-db`.
2. Las que están completamente en minúsculas se siguen buscando sin distinguir mayúsculas: `worker` sigue encontrando `Worker` y `worker-db`.
3. Se decide por separado para cada parte: con `Api,web`, pasan `Api-server` y `WEB-frontend`, pero no `api-server`.
4. Se aplica igual a las exclusiones: con `-Api`, `api-server` pasa y `Api-server` queda fuera.

**Notas**

- Las exclusiones, las alternativas con comas y el campo (botón `Clear name filter`, `Escape`, foco) no cambian en lo demás.
- Los tests existentes del proyecto deben seguir pasando.
