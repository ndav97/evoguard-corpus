# T003 — Avisos de error del filtro de etiquetas coherentes

**Contexto.** En el filtro de etiquetas (`packages/components/src/components/LabelFilter/LabelFilter.jsx`), el aviso de error se queda en pantalla mientras el usuario corrige el texto, hasta que lo cierra a mano. Además, el enlace a la documentación de Kubernetes solo aparece en el aviso de formato: el de longitud no lo muestra (o arrastra el de un error anterior) y el de duplicado deja un enlace vacío.

**Qué hay que hacer**

1. Al modificar el texto del campo del filtro, oculta el aviso de error que hubiera (de formato, de longitud o de duplicado). El texto escrito se conserva.
2. El aviso de longitud muestra el mismo enlace que el de formato: texto del mensaje `dashboard.labelFilter.syntaxMessage` y la misma URL de la documentación de etiquetas de Kubernetes (`kubernetes.io`).
3. El aviso de formato sigue mostrando ese enlace.
4. El aviso de duplicado no muestra ningún enlace (ni siquiera vacío).

**Notas**

- Los textos de los avisos no cambian y el botón de cerrar el aviso sigue funcionando.
- Los tests existentes del proyecto deben seguir pasando.
