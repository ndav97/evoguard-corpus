# T004 — Anunciar los filtros de etiquetas añadidos

**Contexto.** Cuando se añaden filtros en el filtro de etiquetas (`packages/components/src/components/LabelFilter/LabelFilter.jsx`), el campo se vacía y aparecen las etiquetas, pero un lector de pantalla no recibe ninguna confirmación, y el usuario tampoco sabe si alguno de los filtros escritos se omitió por estar ya aplicado.

**Qué hay que hacer**

1. Añade al componente una región de estado (`role="status"`), visualmente oculta (clase `tkn--visually-hidden`, como el botón `Add filter`). Se renderiza siempre y empieza vacía.
2. Cada vez que se añaden filtros, la región muestra cuántos se han añadido (los nuevos, sin contar repetidos dentro del texto escrito), con plural según el número:
   - `Added 1 label filter`
   - `Added 3 label filters`
3. Si además se omitieron filtros por estar ya aplicados, se añade cuántos: `Added 1 label filter, 2 already applied` (el número de omitidos se muestra tal cual).
4. Cuando se muestra cualquier aviso de error (formato, longitud o duplicado), la región se vacía.
5. Usa `intl.formatMessage` con `defaultMessage` (mensajes ICU con `plural`), como el resto del componente.

**Notas**

- La validación y la llamada a `handleAddFilter` no cambian.
- Los tests existentes del proyecto deben seguir pasando.
