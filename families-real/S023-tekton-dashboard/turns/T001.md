# T001 — Validar cada filtro de etiquetas de la lista

**Contexto.** El filtro de etiquetas de las listas (`packages/components/src/components/LabelFilter/LabelFilter.jsx`) admite varios filtros separados por comas (`app:test,env:dev`), pero la validación es incompleta: la expresión regular no está anclada, así que `app:test!` se acepta tal cual; con `app:test,env` se añade una entrada `env` sin valor; el límite de 63 caracteres solo se comprueba en el primer valor, y una coma final produce un filtro vacío.

**Qué hay que hacer**

1. Tras quitar los espacios, divide el texto por comas y **descarta las entradas vacías** (por ejemplo, la de una coma final: `app:test, env:dev,` añade `app=test` y `env=dev`).
2. Cada entrada debe ser, completa, un par `labelKey:labelValue`:
   - la clave admite letras, dígitos, `-`, `_`, `.` y `/` (para prefijos como `tekton.dev/pipeline`);
   - el valor admite letras, dígitos, `-`, `_` y `.`;
   - ambos deben tener al menos un carácter.
   Si alguna entrada no cumple (o no queda ninguna), muestra el aviso de formato no válido que ya existe (`dashboard.labelFilter.invalid`) y no añadas nada.
3. El límite de longitud del valor (más de 63 caracteres no se admite) se aplica a **todas** las entradas; si alguna lo supera, muestra el aviso de longitud que ya existe (`dashboard.labelFilter.invalidLength`) y no añadas nada. Un valor de 63 caracteres es válido.
4. Si todo es válido, se llama a `handleAddFilter` igual que ahora (filtros existentes más los nuevos en formato `clave=valor`, sin repetidos).

**Notas**

- El texto de los avisos no cambia.
- Los tests existentes del proyecto deben seguir pasando.
